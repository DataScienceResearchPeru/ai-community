# Governance

The community grows through transparent contribution and review.

| Level | Participation and responsibility |
| --- | --- |
| Visitor | Reads, clones, and uses public resources. |
| Contributor | Forks, opens Pull Requests and issues, and joins discussions. |
| Community Member | A recurring contributor recognized by the community. |
| AI Builder | Completes challenges, builds documented projects, and contributes actively. |
| Mentor | Reviews Pull Requests, supports learning, moderates issues, and helps with challenges. |
| Maintainer | Approves and merges Pull Requests, maintains projects and releases, and sets technical standards. |

Organization membership is not required to contribute. Mentors receive Triage-level access when needed; maintainers receive the minimum elevated repository access necessary. Organization Owners remain outside this role automation.

Maintainers decide by consensus where possible. Conflicts of interest, security matters, and Code of Conduct reports are handled privately and with care.
