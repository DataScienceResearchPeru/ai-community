# Community scaling

| Participants | Operating model |
| --- | --- |
| 100 | Public contribution flow, lightweight maintainer review, monthly challenge. |
| 500 | Clear labels, issue templates, mentor rotation, project ownership. |
| 1,000 | Dedicated challenge cycles, contributor recognition, documented triage. |
| 5,000 | Public users continue with forks and Pull Requests; organization membership stays optional and limited to active contributors, mentors, and maintainers. |

Public users contribute through forks and Pull Requests. Active contributors may receive optional organization membership. Mentors belong to the mentors team; maintainers belong to the maintainers team. Do not add all participants to the organization.
