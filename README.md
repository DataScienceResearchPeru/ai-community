# DSRP AI Community

> Learn. Build. Share.

An open-source AI community by [Data Science Research Perú](https://www.datascience.pe). This is a practical space to learn, build in public, and contribute to AI projects with clear engineering standards.

## About

We focus on AI Agents, RAG, MCP, AI Engineering, Claude, Codex, Gemini, OpenAI, Python, LLMs, and automation. Everyone can participate through a fork and Pull Request; organization membership is optional.

## What you'll find

- Learning paths in `learning/`
- Hands-on labs in `labs/`
- Reusable project templates in `projects/`
- Open challenges in `challenges/`
- Curated resources in `resources/`

## Getting started

1. Read [the community guide](docs/community-guide.md).
2. Fork this repository and create a feature branch.
3. Choose a lab, challenge, resource, or project idea.
4. Open a Pull Request using the provided template.

## How to contribute

See [CONTRIBUTING.md](CONTRIBUTING.md) and [the contribution guide](docs/contribution-guide.md). Small documentation improvements are welcome alongside projects and challenge submissions.

## Community projects

Propose and discover shared work in [community-projects](community-projects/README.md). Each project should document its problem, architecture, setup, and contributors.

## Challenges

Active challenges live in [challenges/active](challenges/README.md). Submit a documented solution by Pull Request.

## AI Builders

AI Builders complete challenges, publish useful projects, and document what they learn. Recognition is based on quality and helpfulness, not commit volume. See [builders](builders/README.md).

## Contribution levels

`Visitor → Contributor → Community Member → AI Builder → Mentor → Maintainer`

Roles and responsibilities are described in [GOVERNANCE.md](GOVERNANCE.md).

## Community rules

Be constructive, give credit, protect private information, and never commit secrets. Read the [Code of Conduct](CODE_OF_CONDUCT.md) and [Security Policy](SECURITY.md).
