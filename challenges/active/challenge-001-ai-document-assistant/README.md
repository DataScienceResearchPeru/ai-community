# AI Challenge #001 — Build an AI Document Assistant

Build an assistant that answers questions over a small set of documents. Suggested stack: Python, RAG, an LLM, embeddings, and a vector database. You may use Claude, OpenAI, or Gemini.

## Requirements

- Explain ingestion, retrieval, prompting, and evaluation.
- Include setup and safe configuration instructions.
- Do not submit private documents, API keys, or credentials.
- Document limitations and what you learned.

Place starter material in `starter/`, supporting public material in `resources/`, and record submissions in `submissions.md` through Pull Requests.
