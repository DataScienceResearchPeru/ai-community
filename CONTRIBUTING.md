# Contributing

Thank you for improving the community. Contributions happen through forks and Pull Requests.

1. Read the relevant guide and existing content.
2. Fork the repository and create a descriptive feature branch.
3. Make a focused change, document it, and remove any sensitive data.
4. Run the applicable local checks.
5. Open a Pull Request and complete its template.

Use inclusive language, keep changes reviewable, and respond constructively to feedback. For larger work, open an issue or project proposal first.
